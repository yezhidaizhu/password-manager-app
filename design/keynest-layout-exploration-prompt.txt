Use case: ui-mockup
Asset type: mobile UX layout exploration board
Primary request: Create three fundamentally different information architectures for the main vault screen of "KeyNest", a local password manager. This is a fresh design exploration, not a restyle. Do not reuse the familiar top app bar + search field + vertical list + floating add button layout.

Show exactly three straight-on portrait Android app canvases side by side, labeled A, B, and C outside the canvases. Each canvas represents the same vault data: GitHub / octocat, Gmail / user@gmail.com, AWS / dev@company.com, Notion / me@notion.so. Each concept must make account selection, search, favorite state, and adding an account discoverable, but solve the layout differently.

Concept A — Spatial credential stack:
Accounts are represented as a tactile vertical stack of thin credential slabs occupying the main stage. Several slab edges remain visible behind the selected credential. The selected GitHub slab expands in place to expose username and copy/reveal actions. Search is a compact pull-down command surface. Add is integrated into the base of the stack, not floating in a corner. Strong foreground/midground/background depth.

Concept B — Service rail + focus plane:
A narrow sculpted vertical service rail runs along the left edge with recognizable service marks. The rest of the screen is one large focus plane showing the selected GitHub credential, username, masked password, copy/reveal controls, favorite state, and a small account switch indicator. Search and add live in a compact bottom command dock. No list rows and no cards.

Concept C — Search-first aperture:
The screen is organized around a bold cat-keyhole search aperture near the center. Recent and favorite accounts appear as staggered depth layers partially visible around or below it, not as a conventional list or grid. Typing/search state is visually primary; the currently focused account expands from the aperture into a compact action strip. Add account is a clear action within the same command system.

Brand and materials: geometric cat-head/keyhole symbol; vivid emerald #00D084 and deep jade #008F5D; obsidian #050A07; smooth matte carbon #101713; cool white #ECF7F0; muted sage #82968A; restrained amber favorite. Use premium emerald acrylic, smoked translucent layers, subtle edge highlights, soft ambient occlusion, and clear spatial separation. Modern and architectural, not retro skeuomorphic, not cyberpunk, not a game UI.

Typography: crisp Simplified Chinese grotesk sans. Use "KeyNest", "保险库", "搜索账号", "添加账号" only where structurally necessary. Keep account names and usernames legible. Zero letter spacing.

Composition/framing: 2048x1152 landscape board, three equal portrait canvases, fully visible, no phone hardware, no perspective distortion, no overlap, neutral dark studio background. Focus on layout differences rather than decoration.

Constraints: the three concepts must be structurally different, not color or styling variants; no standard app bar; no conventional full-width search bar at the top; no ordinary vertical list rows; no card grid; no floating circular plus button in the top-right or bottom-right; no bottom navigation; no generic Material layout; no nested cards; no decorative feature copy; no gradients used as flat decoration; no stone, marble, cracks, chrome, distressed texture, or heavy bevels; no blue/purple dominance; no emoji; no watermark; no browser UI.
